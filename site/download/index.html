Which Mac do I have?

  1. Click the Apple menu in the top-left corner.
  2. Choose About This Mac.
  3. If Chip says Apple M1 or later, pick Apple silicon. If it says Intel, pick Intel Mac.

Opening it the first time

  1. Windows: if you see “Windows protected your PC”, choose More info, then Run anyway.
  2. Mac: open System Settings → Privacy & Security and click Open Anyway next to vScribe.
  3. Linux AppImage: run chmod +x on the file, or tick “Allow executing” in its properties.
  4. This only happens once. vScribe isn't code-signed yet.

System requirements

  1. Windows 10 or 11, 64-bit. macOS 11 or later. Any 64-bit Linux.
  2. About 500 MB free for the Fast model, or 1.6 GB more for Accurate.
